# Reglas Locales del Proyecto

## Registro de Bitácora y Resumen de Tareas
Al finalizar una instrucción o registrar la bitácora de una tarea, utilizar el formato estándar del skill `task-summary-format`.

## Documentación en Obsidian
Al actualizar la bitácora, registrar el trabajo en Obsidian o documentar el estado de un proyecto, aplicar el flujo del skill `obsidian-project-docs`. Este skill define la estructura de carpetas, plantillas de notas y el flujo obligatorio de 3 pasos (BITACORA.md local → Bitácora diaria Obsidian → Ficha Principal del proyecto).

## Diseño UI/UX y Aplicaciones Web
Al crear o refactorizar pantallas, componentes o interfaces de usuario web, aplicar los estándares definidos en el skill `modern-web-app-design`.

## Seguridad en Aplicaciones Web y APIs
Al desarrollar, modificar o auditar endpoints, autenticación, acceso a base de datos, formularios, manejo de secretos o APIs, seguir estrictamente los estándares del skill `web-app-security`.

## Arquitectura de Evaluaciones y Modales Académicos
Al crear o refactorizar evaluaciones, pautas, hojas de respuesta, motores de impresión/PDF, catálogo curricular o modales compactos de gestión académica, seguir estrictamente los estándares del skill `evaluaciones-academicas-suite`.
