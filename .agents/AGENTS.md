# Reglas Locales del Proyecto

## Registro de Bitácora y Resumen de Tareas
Al finalizar una instrucción o registrar la bitácora de una tarea, utilizar el formato estándar del skill `task-summary-format`.

## Diseño UI/UX y Aplicaciones Web
Al crear o refactorizar pantallas, componentes o interfaces de usuario web, aplicar los estándares definidos en el skill `modern-web-app-design`.
